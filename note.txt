1. Alur app.js > src/app.js > Autoload, Config, Routes
2. Database menggunakan postgresql
3. Struktur tabel sebagai berikut ini, database : node_db
4. Table : 
	Products
		Id [Number]
		Title [Varchar 50]
		Descriptions [Text]
		Price [Decimals]
		IdGroup [Number]
	ProductsGroup
		IdGroup [Number]
		Name [Varchar 50]
	Users
		Username [Varchar 30]
		Password [Varchar 100]
		Name [Varchar 50]
5. Model
	productsModel : Keperluan untuk mengakses data di table Products dan ProductsGroup
	usersModel : Untuk keperluan auth 
6. Controller
	userController : Menangani data berkaitan dengan Users
	productController : Menangani data berkaitan dengan Product
	crudController : Menangani semua CRUD (bersifat general)
7. Config
	autoload : load awal untuk setting yang sering digunakan
	database : setting koneksi database, database yang digunakan saat ini adalah postgresql
	config : pengaturan aplikasi
	routes : routing aplikasi
	appdir : meringkas tampilan path
8. Views
	Component : Merupakan potongan 
	Layout : tempat css ataupun template 
	Screen : tampilan halaman yang akan dilihat user
		Auth
		Form
		Data
9. Asset
    img, icon,font
10. URL yang digunakan : 
		http://localhost:3000/Products/getDataDB/oba : Menampilkan data yang mengandung kata "oba"
		http://localhost:3000/Products/template : Menampilkan landing page yang full CSS dan JS yang estetik
		http://localhost:3000/Products/home-ejs : Menampilkan page yang mengambil komponen footer yang berbeda file serta menampilkan image
		http://localhost:3000/Products/path : Menampilkan path dari file
		http://localhost:3000/Products/Home : Menampilkan simple view yang bukan berformat ejs tetapi html
		http://localhost:3000/Users/77 : Mengambil nilai ID, yaitu bernilai "77"
		http://localhost:3000/form/form : Form input data tetapi hanya untuk ditampilkan tanpa disimpan
		http://localhost:3000/form/storedb : Form input data yang diproses disimpan di dalam database
		http://localhost:3000/form/multidata : Tombol mengirim data (lebih dari satu) berupa JSON namun respon yang diberikan hanya berupa console log
		http://localhost:3000/Products/templatepart : Menampilkan layar landing page yang estetik dan dipecah secara layout komponen seperti bagian Header dan About
